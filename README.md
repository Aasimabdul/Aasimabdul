## What I care about

- **Low RAM, small size.** Plain framework APIs where they are enough, libraries only when they earn their weight.
- **Privacy by default.** Offline wherever possible, no accounts, no analytics.
- **Clean, minimal UI.** Dark navy and a single accent colour, nothing that doesn't need to be on screen.
- **Shipping.** CI on every push, signed releases on tags.
